Flow

Dettatura vocale e note, per Windows.

Flow è un'applicazione desktop personale. Si tiene premuta una scorciatoia, si parla, e il testo trascritto e ripulito compare nel campo in cui si stava scrivendo — in qualsiasi programma.

Cosa fa

  • Dettatura — parli, il testo appare dove stavi scrivendo.
  • Traduzione — parli in italiano, esce in inglese.
  • Note — un tasto apposta per fermare un pensiero: le note restano in un archivio locale, raggruppate per argomento.
  • Eventi — quando una nota contiene una data («lunedì mattina», «a gennaio»), Flow la riconosce e te la propone. Se confermi, l'evento viene creato sul tuo Google Calendar.

Google Calendar

Il collegamento a Google Calendar è facoltativo e serve a una cosa sola: creare, aggiornare ed eliminare gli eventi che l'utente ha esplicitamente confermato dentro Flow. Nient'altro del calendario viene letto o modificato.

Dove stanno i dati. Note, trascrizioni e credenziali restano sul computer di chi usa l'applicazione. Flow non ha un server e non raccoglie niente.

I dettagli sono nelle norme sulla privacy.

In breve, in inglese

Flow is a personal desktop app for Windows: push-to-talk dictation, Italian → English translation, and voice notes kept in a local archive. When a note contains a date, Flow proposes an event; if the user confirms it, the event is created on their Google Calendar using the calendar.events scope. Notes, transcripts and credentials stay on the user's computer — there is no server and nothing is collected.
